# Fuji RAW Converter · 机型与胶片清单

[中文说明](../README.md) · [English](../README.en.md)

X/GFX 各机型另有“默认 / 拍摄设置”。数量包含黑白滤镜变体，不含默认项。所有胶片效果由官方转换组件生成。

Every X/GFX model also has Default / As shot. Counts include monochrome filter variants and exclude the default option. Film rendering uses the official conversion components.
