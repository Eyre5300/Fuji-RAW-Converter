Third-party components / 第三方组件

resources/engine contains the extracted conversion and RAW browsing dependencies
used by this project, not the complete Hyper-Utility installation or updater.
The build copies them into data/engine. Common files are stored only once in
the repository and copied into each engine's directory when building.

RAFCNV / RAFCNVX: Original Fujifilm conversion modules, camera profiles and
color resources. FG05FC09.dll and FG05FC0B.dll are version 6.2.0.27 from the
HS-V3 1.1b updater. Other resources come from the installed Hyper-Utility3.
The 24 FF1/FF2 files (about 145 MiB) are referenced by the S3 Pro and S5 Pro
film-simulation configurations. They are not unused application assets.

browser: PIR030RAF RAW reader and its companion imaging libraries.
Legacy Microsoft runtime DLLs are included where required by these components.

RFCEX: RAW FILE CONVERTER EX 3.0 powered by SILKYPIX, extracted from the
locally installed SILKYPIX Developer Studio 8.0 RFCEX. SILKYPIX64.dll is
version 8.1.20.0, Adwaa Co.,Ltd. The worker uses this exact private ABI;
replacing the DLL with another version is not supported.
SHA256: afdac23b0107aed6e5454af7c810a9d4363ac4e3e99df1b14f9d5825cdf28ad8
Source: https://www.fujifilm-x.com/en-us/products/software/raw-file-converter-ex-powered-by-silkypix/
The bundled subset contains development libraries, camera/color/lens data,
ICC profiles and settings. It does not include the official GUI executable.
extract-rfcex.ps1 reproduces extraction and generates a per-file manifest.
